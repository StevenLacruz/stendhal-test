# El Efecto Stendhal

Web en Astro 7, Tailwind CSS v4, Content Collections y Keystatic (modo local).

## Comandos

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor local en `http://127.0.0.1:4321` |
| | Panel de contenido: `/keystatic` |
| `npm run check` | TypeScript estricto |
| `npm run build` | Build de producción |
| `npm run preview` | Previsualiza el build |

El contenido se edita en `/keystatic` y queda en `src/content/` como JSON y Markdoc.
